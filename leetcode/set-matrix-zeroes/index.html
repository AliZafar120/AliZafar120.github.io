#73 Set Matrix Zeroes Medium
MatrixTime O(rows * cols), two passes over the grid. Space O(1) extra: two booleans, with flags stored in the matrix itself.Open on leetcode.com ↗ Status:

Given a grid of integers, find every cell that holds 0 and set its entire row and entire column to 0. Do it in place. The catch is that newly written zeros must not trigger further clearing; only the zeros present in the original grid count.

Input:  matrix = [[1, 2, 3],
                  [4, 0, 6],
                  [7, 8, 9]]
Output: [[1, 0, 3],
         [0, 0, 0],
         [7, 0, 9]]

Input:  matrix = [[0, 5],
                  [3, 4]]
Output: [[0, 0],
         [0, 4]]
  • 1 ≤ rows, cols ≤ 200
  • Follow-up: O(1) extra space, not O(rows + cols)

from typing import List

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        first_row_zero = any(matrix[0][j] == 0 for j in range(cols))
        first_col_zero = any(matrix[i][0] == 0 for i in range(rows))
        for i in range(1, rows):
            for j in range(1, cols):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0
        for i in range(1, rows):
            for j in range(1, cols):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0
        if first_row_zero:
            for j in range(cols):
                matrix[0][j] = 0
        if first_col_zero:
            for i in range(rows):
                matrix[i][0] = 0
