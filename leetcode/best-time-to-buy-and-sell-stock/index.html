#121 Best Time to Buy and Sell Stock Easy
ArrayTime O(n), one pass. Space O(1), two variables.Open on leetcode.com ↗ Status:

You are given a list prices where prices[i] is the price of one share on day i. You may buy on one day and sell on a later day, at most once. Return the largest profit you can make; if no profitable trade exists, return 0.

Input:  prices = [6, 2, 8, 1, 5]
Output: 6        buy at 2 (day 1), sell at 8 (day 2)

Input:  prices = [9, 7, 4, 3]
Output: 0        prices only fall, so do not trade
  • 1 ≤ len(prices) ≤ 105, 0 ≤ prices[i] ≤ 104
  • You must buy before you sell, and you make at most one trade

Full solution (copy)
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float("inf")
        best = 0
        for price in prices:
            if price < min_price:
                min_price = price
            elif price - min_price > best:
                best = price - min_price
        return best
