#338 Counting Bits Easy
BinaryTime O(n), one constant-time step per number. Space O(n) for the output list.Open on leetcode.com ↗ Status:

Given a non-negative integer n, return a list of length n + 1 where entry i is the number of 1 bits in the binary form of i, for every i from 0 to n. The whole list should be built in O(n) time, i.e. without counting the bits of each number from scratch.

Input:  n = 6
Output: [0, 1, 1, 2, 1, 2, 2]
        0=0  1=1  2=10  3=11  4=100  5=101  6=110

Input:  n = 1
Output: [0, 1]
  • 0 ≤ n ≤ 105
  • Linear time is expected; a built-in popcount per number is not the intended solution

from typing import List

class Solution:
    def countBits(self, n: int) -> List[int]:
        bits = [0] * (n + 1)
        for i in range(1, n + 1):
            bits[i] = bits[i >> 1] + (i & 1)
        return bits
