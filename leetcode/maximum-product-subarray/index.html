#152 Maximum Product Subarray Medium
ArrayTime O(n), one pass. Space O(1), three variables.Open on leetcode.com ↗ Status:

Given a list of integers nums, find the contiguous run of one or more elements whose product is as large as possible and return that product. Elements may be negative or zero, and the answer is guaranteed to fit in a 32-bit integer.

Input:  nums = [2, -3, -4, 0, 5]
Output: 24         the run [2, -3, -4]

Input:  nums = [-5, 0, -2]
Output: 0          any run containing the 0, or just [0]
  • 1 ≤ len(nums) ≤ 2 * 104, -10 ≤ nums[i] ≤ 10
  • The run must contain at least one element

from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        best = nums[0]
        cur_max = cur_min = nums[0]
        for num in nums[1:]:
            if num < 0:
                cur_max, cur_min = cur_min, cur_max
            cur_max = max(num, cur_max * num)
            cur_min = min(num, cur_min * num)
            best = max(best, cur_max)
        return best
