#190 Reverse Bits Easy
BinaryTime O(1): a fixed 32 iterations. Space O(1).Open on leetcode.com ↗ Status:

Given a non-negative integer n that represents a 32-bit unsigned value, reverse the order of its 32 bits and return the resulting integer. Bit 0 (the least significant) moves to bit 31, bit 1 moves to bit 30, and so on. Leading zeros count: they become trailing zeros.

Input:  n = 6          00000000000000000000000000000110
Output: 1610612736     01100000000000000000000000000000

Input:  n = 1
Output: 2147483648     a single 1 moves from bit 0 to bit 31
  • 0 ≤ n < 232; the input is treated as exactly 32 bits
  • The result is also an unsigned 32-bit value
Select a line of code to see what it does.
Full solution (copy)
class Solution:
    def reverseBits(self, n: int) -> int:
        result = 0
        for _ in range(32):
            result = (result << 1) | (n & 1)
            n >>= 1
        return result
