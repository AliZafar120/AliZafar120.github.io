#91 Decode Ways Medium
Dynamic ProgrammingTime O(n), one pass over the digits. Space O(1), two rolling counters.Open on leetcode.com ↗ Status:

Letters are encoded as numbers: A is 1, B is 2, up to Z is 26, and the codes are written one after another with no separators. Given a string of digits, count how many different letter strings could have produced it. A piece such as "0" or "07" is not a valid code, and a string with no valid decoding has 0 ways.

Input:  s = "2611"
Output: 4        2|6|1|1, 26|1|1, 2|6|11, 26|11

Input:  s = "1201"
Output: 1        only 1|20|1, since "01" and a lone "0" are not codes
  • 1 ≤ len(s) ≤ 100, digits only
  • s may contain leading zeros (then the answer is 0)

class Solution:
    def numDecodings(self, s: str) -> int:
        if s[0] == "0":
            return 0
        prev, cur = 1, 1
        for i in range(1, len(s)):
            nxt = 0
            if s[i] != "0":
                nxt += cur
            if s[i - 1] == "1" or (s[i - 1] == "2" and s[i] <= "6"):
                nxt += prev
            prev, cur = cur, nxt
        return cur
