#230 Kth Smallest Element in a BST Medium
TreeTime O(h + k): the initial dive costs the height, then each of the k visits is amortised O(1). Space O(h) for the stack.Open on leetcode.com ↗ Status:

Given the root of a binary search tree and an integer k, return the k-th smallest value in the tree, counting from 1. The BST property guarantees that an inorder traversal visits the values in increasing order.

Input:  root = [7, 3, 9, 1, 5],  k = 3
            7
           / \
          3   9
         / \
        1   5
Output: 5             sorted values are 1, 3, 5, 7, 9

Input:  root = [2, 1],  k = 1
Output: 1
  • 1 ≤ k ≤ number of nodes ≤ 104
  • 0 ≤ Node.val ≤ 104

from typing import Optional

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        stack = []
        node = root
        while True:
            while node:
                stack.append(node)
                node = node.left
            node = stack.pop()
            k -= 1
            if k == 0:
                return node.val
            node = node.right
