#1 Two Sum Easy
ArrayTime O(n), one pass. Space O(n) for the map in the worst case.Open on leetcode.com ↗ Status:

You are given a list of integers nums and a target integer. Exactly one pair of positions holds two numbers that add up to the target. Return those two indices, in any order. The same position may not be used twice.

Input:  nums = [3, 8, 11, 2], target = 10
Output: [1, 3]        because nums[1] + nums[3] = 8 + 2 = 10

Input:  nums = [5, 5], target = 10
Output: [0, 1]
  • 2 ≤ len(nums) ≤ 104, values and target fit in a 32-bit integer
  • Exactly one valid answer exists

from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, num in enumerate(nums):
            need = target - num
            if need in seen:
                return [seen[need], i]
            seen[num] = i
        return []
