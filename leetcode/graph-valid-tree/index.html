#261 Graph Valid Tree Medium premium
GraphTime O(n + E), and since E = n - 1 when we get past the first check, effectively O(n). Space O(n) for the adjacency list, the seen set and the stack.Open on leetcode.com ↗ Status:

You have n nodes labelled 0 to n - 1 and a list of undirected edges, each given as a pair [a, b]. Decide whether these edges form a valid tree: a graph that is connected (every node can reach every other) and has no cycles. Return true if so, otherwise false.

Input:  n = 5, edges = [[0, 1], [0, 2], [1, 3], [1, 4]]
Output: true                0
                           / \
                          1   2
                         / \
                        3   4

Input:  n = 4, edges = [[0, 1], [1, 2], [2, 0]]
Output: false       0-1-2 form a cycle, and node 3 is unreachable
  • 1 ≤ n ≤ 2000, 0 ≤ len(edges) ≤ 5000
  • No self loops and no duplicate edges
  • A single node with no edges is a valid tree

from typing import List

class Solution:
    def validTree(self, n: int, edges: List[List[int]]) -> bool:
        if len(edges) != n - 1:
            return False
        adj = [[] for _ in range(n)]
        for a, b in edges:
            adj[a].append(b)
            adj[b].append(a)
        seen = {0}
        stack = [0]
        while stack:
            cur = stack.pop()
            for nb in adj[cur]:
                if nb not in seen:
                    seen.add(nb)
                    stack.append(nb)
        return len(seen) == n
