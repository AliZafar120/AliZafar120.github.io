#252 Meeting Rooms Easy premium
IntervalTime O(n log n) for the sort, then O(n) for the scan. Space O(1) extra beyond the in-place sort.Open on leetcode.com ↗ Status:

You are given a list of meetings, each as a pair [start, end] meaning the meeting occupies the half-open time span from start up to but not including end. One person has to attend every meeting. Return True if that is possible, meaning no two meetings overlap in time, and False otherwise. A meeting that ends at time t and another that starts at t do not conflict.

Input:  intervals = [[9,10], [13,15], [10,12]]
Output: True         sorted: 9-10, 10-12, 13-15, no clashes

Input:  intervals = [[1,5], [3,7]]
Output: False        3 falls inside [1,5)
  • 0 ≤ len(intervals) ≤ 104, 0 ≤ start < end ≤ 106
  • Meetings are not given in any particular order

from typing import List

class Solution:
    def canAttendMeetings(self, intervals: List[List[int]]) -> bool:
        intervals.sort(key=lambda x: x[0])
        for i in range(1, len(intervals)):
            if intervals[i][0] < intervals[i - 1][1]:
                return False
        return True
