#105 Construct Binary Tree from Preorder and Inorder Traversal Medium
TreeTime O(n), each node is created once with O(1) lookups. Space O(n) for the index map plus O(h) recursion stack.Open on leetcode.com ↗ Status:

You are given two lists describing the same binary tree: preorder lists the node values as visited root, left subtree, right subtree, and inorder lists them as left subtree, root, right subtree. All values are distinct. Rebuild the tree and return its root.

Input:  preorder = [6, 2, 1, 4, 8],  inorder = [1, 2, 4, 6, 8]
Output: [6, 2, 8, 1, 4]
            6
           / \
          2   8
         / \
        1   4

Input:  preorder = [1, 2],  inorder = [2, 1]
Output: [1, 2]        2 is before 1 in inorder, so 2 is a left child
  • 1 ≤ len(preorder) = len(inorder) ≤ 3000
  • All values are distinct, and both lists describe a valid tree

from typing import List, Optional

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        index = {val: i for i, val in enumerate(inorder)}
        pre = 0
        def build(lo: int, hi: int) -> Optional[TreeNode]:
            nonlocal pre
            if lo > hi:
                return None
            val = preorder[pre]
            pre += 1
            node = TreeNode(val)
            mid = index[val]
            node.left = build(lo, mid - 1)
            node.right = build(mid + 1, hi)
            return node
        return build(0, len(inorder) - 1)
