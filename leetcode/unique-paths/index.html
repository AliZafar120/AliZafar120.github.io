#62 Unique Paths Medium
Dynamic ProgrammingTime O(m * n), one addition per cell. Space O(n) for the single rolling row.Open on leetcode.com ↗ Status:

A robot starts in the top-left cell of an m by n grid and wants to reach the bottom-right cell. At each move it may go one cell right or one cell down, never left or up. Count the number of distinct routes.

Input:  m = 3, n = 4
Output: 10

Input:  m = 1, n = 7
Output: 1        a single row: the only route is straight right
  • 1 ≤ m, n ≤ 100
  • The answer fits in a 32-bit integer
Select a line of code to see what it does.
Full solution (copy)
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        row = [1] * n
        for _ in range(1, m):
            for j in range(1, n):
                row[j] += row[j - 1]
        return row[-1]
