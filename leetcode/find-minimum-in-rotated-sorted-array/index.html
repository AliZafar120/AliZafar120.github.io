#153 Find Minimum in Rotated Sorted Array Medium
ArrayTime O(log n), the window halves every step. Space O(1).Open on leetcode.com ↗ Status:

A list of distinct integers was sorted in increasing order and then rotated: some prefix was cut off and appended to the end. For example [1, 3, 5, 7, 9] rotated by 3 becomes [5, 7, 9, 1, 3]. Given the rotated list, return its smallest element in O(log n) time.

Input:  nums = [5, 7, 9, 1, 3]
Output: 1

Input:  nums = [2, 4, 6]
Output: 2          rotated by 0, already sorted
  • 1 ≤ len(nums) ≤ 5000, all values distinct
  • The list was sorted ascending before rotation; O(log n) is required

from typing import List

class Solution:
    def findMin(self, nums: List[int]) -> int:
        lo, hi = 0, len(nums) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if nums[mid] > nums[hi]:
                lo = mid + 1
            else:
                hi = mid
        return nums[lo]
