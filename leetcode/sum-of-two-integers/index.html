#371 Sum of Two Integers Medium
BinaryTime O(1): at most 32 iterations regardless of input. Space O(1).Open on leetcode.com ↗ Status:

Return the sum of two integers a and b without using the + or - operators anywhere in your code. Both inputs and the result fit in a signed 32-bit integer, so negative numbers must be handled correctly.

Input:  a = 5, b = 3
Output: 8

Input:  a = -2, b = 1
Output: -1
  • -1000 ≤ a, b ≤ 1000
  • The operators + and - are forbidden; bit operators are allowed

Full solution (copy)
class Solution:
    def getSum(self, a: int, b: int) -> int:
        MASK = 0xFFFFFFFF
        MAX_INT = 0x7FFFFFFF
        while b != 0:
            carry = ((a & b) << 1) & MASK
            a = (a ^ b) & MASK
            b = carry
        return a if a <= MAX_INT else ~(a ^ MASK)
