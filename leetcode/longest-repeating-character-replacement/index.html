#424 Longest Repeating Character Replacement Medium
StringTime O(n): each index enters and leaves the window at most once. Space O(1), the count dict has at most 26 keys.Open on leetcode.com ↗ Status:

You are given a string of uppercase letters and an integer k. You may change at most k characters to any other uppercase letter. Return the length of the longest substring that can be turned into a run of one repeated letter using at most k changes.

Input:  s = "AABCCBB", k = 2
Output: 5            "BCCBB" -> change the two C's -> "BBBBB"

Input:  s = "ABC", k = 0
Output: 1
  • 1 ≤ len(s) ≤ 105, only uppercase English letters
  • 0 ≤ k ≤ len(s)

from collections import defaultdict

class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        count = defaultdict(int)
        left = 0
        max_freq = 0
        best = 0
        for right, ch in enumerate(s):
            count[ch] += 1
            max_freq = max(max_freq, count[ch])
            while (right - left + 1) - max_freq > k:
                count[s[left]] -= 1
                left += 1
            best = max(best, right - left + 1)
        return best
