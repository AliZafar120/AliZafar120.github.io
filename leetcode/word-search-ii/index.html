#212 Word Search II Hard
TreeTime O(R * C * 4 * 3^(L-1)) in the worst case, where L is the longest word, but the trie pruning makes typical inputs far faster. Space O(total characters in words) for the trie plus O(L) recursion depth.Open on leetcode.com ↗ Status:

You are given a grid of lowercase letters board and a list of distinct words. Return every word that can be spelled by starting at some cell and moving to a horizontally or vertically adjacent cell for each following letter, never reusing a cell within one word. Words may be returned in any order.

Input:  board = [["c","a","t"],
                 ["o","d","e"],
                 ["r","n","s"]]
        words = ["cat", "code", "corn", "rod", "ten", "cats"]
Output: ["cat", "code", "corn", "rod"]
        "ten" fails: after t -> e the only "n" is diagonal to "e";
        "cats" fails: it needs an "s" next to "t", and only "e" is there

Input:  board = [["a"]],  words = ["a", "aa"]
Output: ["a"]
  • 1 ≤ rows, cols ≤ 12; 1 ≤ len(words) ≤ 3 · 104; 1 ≤ len(word) ≤ 10
  • All words are distinct and consist of lowercase letters

from typing import List

class Solution:
    def findWords(self, board: List[List[str]], words: List[str]) -> List[str]:
        root = {}
        for word in words:
            node = root
            for ch in word:
                node = node.setdefault(ch, {})
            node["$"] = word
        rows, cols = len(board), len(board[0])
        found = []
        def dfs(r: int, c: int, parent: dict) -> None:
            ch = board[r][c]
            node = parent[ch]
            word = node.pop("$", None)
            if word is not None:
                found.append(word)
            board[r][c] = "#"
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and board[nr][nc] in node:
                    dfs(nr, nc, node)
            board[r][c] = ch
            if not node:
                parent.pop(ch)
        for r in range(rows):
            for c in range(cols):
                if board[r][c] in root:
                    dfs(r, c, root)
        return found
