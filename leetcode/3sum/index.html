#15 3Sum Medium
ArrayTime O(n^2): O(n log n) sort plus an O(n) two-pointer walk for each of n first elements. Space O(1) extra beyond the output (sorting in place).Open on leetcode.com ↗ Status:

Given a list of integers nums, return every distinct triple of values [a, b, c], taken from three different positions, such that a + b + c = 0. Two triples with the same three values in a different order count as the same triple and must appear only once. The output order does not matter.

Input:  nums = [-3, 1, 2, -1, 0, 2]
Output: [[-3, 1, 2], [-1, 0, 1]]

Input:  nums = [1, 2, 3]
Output: []
  • 3 ≤ len(nums) ≤ 3000, -105 ≤ nums[i] ≤ 105
  • The result must not contain duplicate triples

from typing import List

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        result = []
        for i in range(len(nums) - 2):
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            lo, hi = i + 1, len(nums) - 1
            while lo < hi:
                total = nums[i] + nums[lo] + nums[hi]
                if total < 0:
                    lo += 1
                elif total > 0:
                    hi -= 1
                else:
                    result.append([nums[i], nums[lo], nums[hi]])
                    lo += 1
                    while lo < hi and nums[lo] == nums[lo - 1]:
                        lo += 1
        return result
