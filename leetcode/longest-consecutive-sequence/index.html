#128 Longest Consecutive Sequence Medium
GraphTime O(n): building the set is linear and every element is walked forward at most once. Space O(n) for the set.Open on leetcode.com ↗ Status:

Given an unsorted list of integers, find the length of the longest run of consecutive values that all appear somewhere in the list. The values do not have to be adjacent in the input, and duplicates do not make a run longer. Your algorithm must run in O(n) time, so sorting is off the table.

Input:  nums = [50, 3, 2, 100, 4, 1]
Output: 4            the run 1, 2, 3, 4

Input:  nums = [7, 7, 7]
Output: 1
  • 0 ≤ len(nums) ≤ 105
  • -109 ≤ nums[i] ≤ 109

from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        num_set = set(nums)
        best = 0
        for num in num_set:
            if num - 1 in num_set:
                continue
            length = 1
            while num + length in num_set:
                length += 1
            best = max(best, length)
        return best
