#143 Reorder List Medium
Linked ListTime O(n): three linear passes (find middle, reverse, interleave). Space O(1), only a fixed number of pointers.Open on leetcode.com ↗ Status:

Given the head of a singly linked list L0 -> L1 -> ... -> Ln, rearrange its nodes in place into the order L0 -> Ln -> L1 -> Ln-1 -> L2 -> Ln-2 -> ..., alternating between the front and the back. Only pointers may be changed, not node values, and the method returns nothing.

Input:  head = 10 -> 20 -> 30 -> 40 -> 50
Output: 10 -> 50 -> 20 -> 40 -> 30

Input:  head = 1 -> 2 -> 3 -> 4
Output: 1 -> 4 -> 2 -> 3
  • 1 ≤ number of nodes ≤ 5 * 104
  • 1 ≤ Node.val ≤ 1000

from typing import Optional

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        if not head or not head.next:
            return
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        second = slow.next
        slow.next = None
        prev = None
        while second:
            nxt = second.next
            second.next = prev
            prev = second
            second = nxt
        first, second = head, prev
        while second:
            tmp1, tmp2 = first.next, second.next
            first.next = second
            second.next = tmp1
            first, second = tmp1, tmp2
