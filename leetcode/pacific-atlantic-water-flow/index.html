#417 Pacific Atlantic Water Flow Medium
GraphTime O(rows * cols): each cell is marked at most once per ocean, so at most twice. Space O(rows * cols) for the two sets and the recursion stack.Open on leetcode.com ↗ Status:

A rectangular island is described by a grid of heights. The Pacific Ocean touches the top edge and the left edge; the Atlantic touches the bottom edge and the right edge. Rain falling on a cell can flow to any of its four neighbours whose height is less than or equal to its own, and it drains into an ocean when it leaves the grid. Return the coordinates of every cell from which water can reach both oceans, in any order.

Input:  heights = [[1, 3, 2],
                   [4, 2, 5]]
Output: [[0, 1], [0, 2], [1, 0], [1, 2]]
        (0,0) is on the Pacific coast but both neighbours are higher,
        so its water never reaches the Atlantic

Input:  heights = [[5]]
Output: [[0, 0]]
  • 1 ≤ rows, cols ≤ 200
  • 0 ≤ heights[r][c] ≤ 105

from typing import List

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        if not heights or not heights[0]:
            return []
        rows, cols = len(heights), len(heights[0])
        pacific, atlantic = set(), set()
        def dfs(r: int, c: int, reached: set) -> None:
            reached.add((r, c))
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if (0 <= nr < rows and 0 <= nc < cols
                        and (nr, nc) not in reached
                        and heights[nr][nc] >= heights[r][c]):
                    dfs(nr, nc, reached)
        for c in range(cols):
            dfs(0, c, pacific)
            dfs(rows - 1, c, atlantic)
        for r in range(rows):
            dfs(r, 0, pacific)
            dfs(r, cols - 1, atlantic)
        return [[r, c] for r, c in pacific & atlantic]
