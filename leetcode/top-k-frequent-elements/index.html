#347 Top K Frequent Elements Medium
HeapTime O(n log k): O(n) to count, then one O(log k) heap operation per distinct value. Space O(n) for the counts plus O(k) for the heap.Open on leetcode.com ↗ Status:

Given a list of integers and a number k, return the k values that occur most often. The answer may be in any order. You may assume the answer is unique, meaning there is no tie at the boundary that would make two different sets of k elements valid.

Input:  nums = [4, 4, 4, 7, 7, 2, 9, 9, 9, 9], k = 2
Output: [9, 4]        9 appears 4 times, 4 appears 3 times

Input:  nums = [5], k = 1
Output: [5]
  • 1 ≤ len(nums) ≤ 105, 1 ≤ k ≤ number of distinct values
  • Follow-up: better than O(n log n)

from collections import Counter
import heapq
from typing import List

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        counts = Counter(nums)
        heap: List[tuple] = []
        for num, freq in counts.items():
            heapq.heappush(heap, (freq, num))
            if len(heap) > k:
                heapq.heappop(heap)
        return [num for freq, num in heap]
