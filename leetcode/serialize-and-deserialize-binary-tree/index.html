#297 Serialize and Deserialize Binary Tree Hard
TreeTime O(n) for each direction, every node and null marker is touched once. Space O(n) for the token list plus O(h) recursion depth.Open on leetcode.com ↗ Status:

Design a class Codec that turns a binary tree into a string and back. serialize(root) must produce a string from which deserialize(s) rebuilds a tree with exactly the same shape and values. The string format is entirely up to you; the only requirement is that the round trip is lossless. Node values may be negative and have several digits.

Input:  root = [1, 2, 3, null, null, 4, 5]
          1
         / \
        2   3
           / \
          4   5
serialize   -> "1,2,#,#,3,4,#,#,5,#,#"   (one possible encoding)
deserialize -> the same tree, level order [1, 2, 3, null, null, 4, 5]

Input:  root = []
serialize   -> "#"
deserialize -> empty tree
  • 0 ≤ number of nodes ≤ 104
  • -1000 ≤ Node.val ≤ 1000

from typing import Optional

class Codec:
    def serialize(self, root: Optional[TreeNode]) -> str:
        parts = []
        def walk(node: Optional[TreeNode]) -> None:
            if node is None:
                parts.append("#")
                return
            parts.append(str(node.val))
            walk(node.left)
            walk(node.right)
        walk(root)
        return ",".join(parts)
    def deserialize(self, data: str) -> Optional[TreeNode]:
        tokens = iter(data.split(","))
        def build() -> Optional[TreeNode]:
            val = next(tokens)
            if val == "#":
                return None
            node = TreeNode(int(val))
            node.left = build()
            node.right = build()
            return node
        return build()
