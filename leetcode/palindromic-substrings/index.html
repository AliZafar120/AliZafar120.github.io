#647 Palindromic Substrings Medium
StringTime O(n^2): 2n - 1 centers, each expanding at most n/2 steps. Space O(1).Open on leetcode.com ↗ Status:

Given a string s, count how many of its contiguous substrings are palindromes. Substrings are identified by their position, so the same text appearing at two different places counts twice. Every single character is a palindrome on its own.

Input:  s = "xyx"
Output: 4             "x", "y", "x", "xyx"

Input:  s = "zzz"
Output: 6             "z" x3, "zz" x2, "zzz" x1
  • 1 ≤ len(s) ≤ 1000
  • s consists of lowercase English letters

Full solution (copy)
class Solution:
    def countSubstrings(self, s: str) -> int:
        total = 0
        def expand(lo: int, hi: int) -> int:
            count = 0
            while lo >= 0 and hi < len(s) and s[lo] == s[hi]:
                count += 1
                lo -= 1
                hi += 1
            return count
        for i in range(len(s)):
            total += expand(i, i)
            total += expand(i, i + 1)
        return total
