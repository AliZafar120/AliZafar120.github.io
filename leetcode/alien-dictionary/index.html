#269 Alien Dictionary Hard premium
GraphTime O(C) where C is the total number of characters in all words: building edges touches each character once and the sort is linear in letters plus edges (at most 26 letters and 26 * 25 edges). Space O(1) beyond the input, since the graph has at most 26 nodes.Open on leetcode.com ↗ Status:

An alien language uses the lowercase English letters but puts them in an unknown order. You are given a list of words that is already sorted according to that alien alphabet. Recover the alphabet: return a string containing every letter that appears in the words, exactly once, in a valid alien order. If several orders are consistent with the words, any one is accepted. If no order is consistent (the words imply a contradiction, or a word is followed by its own proper prefix, which can never be sorted), return the empty string.

Input:  words = ["ba", "bc", "ac", "cab"]
Output: "bac"        ba < bc tells us a < c; bc < ac tells us b < a

Input:  words = ["abc", "ab"]
Output: ""           a word cannot come after its own prefix

Input:  words = ["x", "y", "x"]
Output: ""           x < y and y < x is a contradiction
  • 1 ≤ len(words) ≤ 100, 1 ≤ len(words[i]) ≤ 100
  • Words contain only lowercase English letters
  • Letters that never appear in the input must not appear in the output

from collections import deque
from typing import List

class Solution:
    def alienOrder(self, words: List[str]) -> str:
        adj = {ch: set() for word in words for ch in word}
        indegree = {ch: 0 for ch in adj}
        for first, second in zip(words, words[1:]):
            if len(first) > len(second) and first.startswith(second):
                return ""
            for a, b in zip(first, second):
                if a != b:
                    if b not in adj[a]:
                        adj[a].add(b)
                        indegree[b] += 1
                    break
        queue = deque(ch for ch in adj if indegree[ch] == 0)
        order = []
        while queue:
            ch = queue.popleft()
            order.append(ch)
            for nxt in adj[ch]:
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    queue.append(nxt)
        return "".join(order) if len(order) == len(adj) else ""
