#200 Number of Islands Medium
GraphTime O(rows * cols): every cell is visited by the scan once and sunk at most once. Space O(rows * cols) in the worst case for the recursion stack (a grid that is all land).Open on leetcode.com ↗ Status:

You are given a grid of characters where "1" is land and "0" is water. An island is a group of land cells connected horizontally or vertically (not diagonally), and everything outside the grid counts as water. Count how many islands there are.

Input:  grid = [["1","1","0","0"],
                ["0","1","0","1"],
                ["0","0","0","1"],
                ["1","0","0","0"]]
Output: 3        the top-left blob, the right column pair, the bottom-left cell

Input:  grid = [["0","0"],
                ["0","0"]]
Output: 0
  • 1 ≤ rows, cols ≤ 300
  • Every cell is either "0" or "1"

from typing import List

class Solution:
    def numIslands(self, grid: List[List[str]]) -> int:
        if not grid:
            return 0
        rows, cols = len(grid), len(grid[0])
        count = 0
        def sink(r: int, c: int) -> None:
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != "1":
                return
            grid[r][c] = "0"
            sink(r + 1, c)
            sink(r - 1, c)
            sink(r, c + 1)
            sink(r, c - 1)
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == "1":
                    count += 1
                    sink(r, c)
        return count
