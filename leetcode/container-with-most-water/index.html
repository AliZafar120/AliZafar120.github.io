#11 Container With Most Water Medium
ArrayTime O(n), each pointer moves at most n steps in total. Space O(1).Open on leetcode.com ↗ Status:

You are given a list height of vertical wall heights standing at positions 0, 1, 2, ... along a line. Pick two walls; together with the ground they form a container whose capacity is the distance between them times the height of the shorter wall (water would spill over the shorter one). Return the largest capacity any pair of walls can hold.

Input:  height = [3, 9, 2, 7, 5]
Output: 15        walls at index 1 (9) and 4 (5): width 3, height 5

Input:  height = [2, 2]
Output: 2
  • 2 ≤ len(height) ≤ 105, 0 ≤ height[i] ≤ 104
  • Walls cannot be tilted; the shorter wall sets the water level

Full solution (copy)
from typing import List

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        best = 0
        while left < right:
            width = right - left
            area = width * min(height[left], height[right])
            best = max(best, area)
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return best
