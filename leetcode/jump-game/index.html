#55 Jump Game Medium
Dynamic ProgrammingTime O(n), one pass. Space O(1), a single integer.Open on leetcode.com ↗ Status:

You stand on the first position of an array. Each value tells you the maximum number of positions you may jump forward from there (you can jump fewer). Decide whether it is possible to reach the last position.

Input:  nums = [2, 3, 1, 0, 4]
Output: True        0 -> 1 -> 4

Input:  nums = [3, 1, 0, 0, 2]
Output: False       index 3 is the farthest you can get, and it has 0 jump
  • 1 ≤ len(nums) ≤ 104
  • 0 ≤ nums[i] ≤ 105
Select a line of code to see what it does.
Full solution (copy)
from typing import List

class Solution:
    def canJump(self, nums: List[int]) -> bool:
        farthest = 0
        for i, step in enumerate(nums):
            if i > farthest:
                return False
            farthest = max(farthest, i + step)
        return True
