Story memory
    How this works

    Each world is a JSON file: characters, style, an opening, and for plotted worlds a story spine of acts and major events with entry flags, variants, and a few pivotal choices. Every turn runs two model calls. The narrator writes the scene from the world card, the current event's brief, the story flags, recent memory notes, and the last turns. The director then returns a small JSON record: whether the event's goal was met, which flags to set, a one-line memory note, and an image prompt for a future scene illustrator. Ordinary choices change the scene; only pivot choices change which version of later events you get. With the in-browser engine the weights download once from the MLC CDN, are cached, and run on your GPU through WebGPU, so nothing leaves your machine. Saves live in this browser; use Export to keep one.
